# Strategi Niche — Dual Track ID + EN

Keputusan: **dua mesin penghasil dalam satu sistem**.

## Kenapa dual track

| | Track ID | Track EN |
|---|---|---|
| Akun | primefinds.id (IG) + TikTok (rebrand dewa_gacor20 / akun baru) | akun TikTok/IG/YouTube **baru, muka-bisu** |
| Niche | finds/produk fisik impulse-buy | demo AI tools / SaaS / gadget |
| Sumber komisi | Shopee Affiliate + TikTok Shop Affiliate | program recurring luar negeri (Notion, Canva, NordVPN, dll) |
| Komisi | 1–25% sekali beli | 20–80% **recurring** (setiap bulan, selama pelanggan langganan) |
| Modal | nol | nol |
| Risiko | rendah | rendah (beda akun, beda platform risk) |
| Bahasa | Indonesia | English |
| Ceiling | sedang | tinggi (CPM luar 5–10x, komisi bulanan menumpuk) |

Satu kegagalan di track satu tidak menggoyang track lainnya. Kalau TikTok ID kena
penalti, EN tetap jalan, dan sebaliknya.

## Track ID — findings produk fisik (primefinds.id)

- **Kriteria produk**: harga Rp15.000–150.000 (impulse buy), komisi ≥10%, terjual
  ratusan+, rating ≥4.5. Masalah harian: dapur, rapi-rapi, mandi, aksesoris HP.
- **Modal**: nol. Mulai dari **Link-Share Only** (TikTok Shop affiliate di bawah
  600 follower tetap bisa komisi lewat link). 600 follower = naik kelas otomatis.
- **Akun TikTok lama** (@dewa_gacor20, kosong): **rebrand total** — ganti nama,
  bio, hapus unggahan lama kalau ada. Nama "gacor" tercatat identik komunitas judi
  slot — itu magnet shadowban. Ganti jadi nama finds (mis. @primefinds.id juga).
- **Frekuensi**: 2–3 video/hari dari sistem + kamu approve.

## Track EN — demo AI tools / SaaS (muka-bisu)

Riset faceless affiliate 2026 (OutlierKit, brandID, clippie.ai) sepakat satu hal:
**yang jual di format tanpa wajah adalah produk yang bisa didemokan di layar**.

- ✅ **Ambil**: AI tools & SaaS (komisi 20–50% recurring), web hosting, productivity
  tools. Screen-recording = bukti kerja produk = pengganti kepercayaan personal.
- ❌ **Tinggalkan**: suplemen/health, kartu kredit, kelas/mentoring "cara kaya" —
  semua butuh wajah + bukti personal, dan kategori make-money penuh scam-fluencer
  yang audiens sudah filter.
- **Bukti angka**: RPM finance/software $15–40 vs entertainment $2–8. Satu referral
  SaaS $99/bulan × 30% recurring = ~$30/bulan × 30 referral ≈ **$900/bulan** dari
  satu video yang tetap hidup bertahun-tahun.
- **Format**: hook 3 detik → demo singkat tool menyelesaikan masalah → CTA link di
  bio/deskripsi. Naskah + suara (en-US-JennyNeural) semua otomatis.
- **Peran kamu**: 5 menit/hari approve. sisanya sistem.

## Urutan eksekusi (jangan dilompati)

1. Minggu 1–2: setup semua (SETUP.md) + jalankan pipeline ID dulu (paling mudah).
2. Minggu 3: tambah seed EN (5 program di `data/seed_en_offers.sample.sql`) +
   bikin akun EN muka-bisu (nama netral, tanpa jejak ID).
3. Bulan 2: kumpulkan 600 follower TikTok ID → daftar affiliate penuh.
4. Bulan 3+: kalau EN mulai ada konversi, naikkan porsi EN (POSTS_PER_DAY_EN).

## Kesalahan yang harus dihindari

- Pindah niche tiap minggu. Algoritma butuh 30+ video untuk "ngerti" akunmu.
- 100% konten promosi. Campur 70% edukasi/hiburan findings, 30% hard-sell.
- Membeli follower. Matiin monetisasi selamanya.
- Spam komentar/kirim link massal. Risiko banned tertinggi yang ada.
